# aMC Windows 客户端 · 视觉方向定稿

本目录存放 2026-09 视觉方向评审的全部 demo。5 份 demo 共用同一套真实感的「唤取分析」界面与数据，仅设计语言不同，便于横向对比。

## 定稿结论

**采用方向 01「曜黑 · 液态玻璃」（Obsidian Liquid Glass）**，理由：

1. 黑金配色与《鸣潮》品牌视觉（黑底金饰）天然契合，产品归属感强；
2. 液态玻璃（动态折射/高光边缘/环境光晕）是 2026 年主流前沿方向（Apple Liquid Glass 体系）；
3. 整体气质最接近成熟商业产品，信息密度与呼吸感平衡最好，适合日常高频使用；
4. 吸收方向 02「战术终端」的等宽数字（tabular-nums / mono）纪律用于数据密集区，形成"玻璃体系 + 精密数据"的混合语言。

其余 4 版源码保留，验收后如需切换方向可基于对应文件重制主题层（前端将主题令牌化，切换成本可控）。

## 预览方式

```bash

node _serve.mjs
# 浏览器打开 http://127.0.0.1:8123/01-liquid-glass.html
```

或直接双击 HTML 文件（无外部依赖，离线可开）。

## 设计令牌基准（方向 01，实现期以此为唯一视觉基准）

- 底色 `#050507`，环境光晕：金 `rgba(232,163,61,.34)` / 紫 `rgba(124,92,255,.26)` / 青 `rgba(94,196,180,.12)`
- 玻璃面板：`linear-gradient(165deg, rgba(255,255,255,.075), rgba(255,255,255,.026))` + `backdrop-filter: blur(30px) saturate(1.55)` + 1px 高光顶边 + 22px 圆角
- 强调金渐变：`#FBE29A → #E8A33D → #C97F1E`；成功绿 `#7DE0A8`；警示紫 `#BCA8F7`
- 文本四级：`rgba(255,255,255,.92 / .55 / .34)`；小标签 10px + 0.3em 字距
- 数字一律 `font-variant-numeric: tabular-nums`，数据密集处用 `"Cascadia Code", Consolas, monospace`
- 动效：入场 `translateY(16px)→0` 阶梯延迟 70ms/级，数字 count-up 1.1s cubic-bezier(.2,.7,.2,1)
